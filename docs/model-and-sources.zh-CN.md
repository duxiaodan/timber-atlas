# 模型资料与限制

[English](model-and-sources.md) | 简体中文

木构图志 · Timber Atlas 将佛光寺东大殿呈现为可探索的构件及连接关系，适合结合资料说明学习建筑结构。

## 如何理解模型

选择构件后，可在构件札记中查看作用、连接关系和参考资料。资料标签说明该构件有哪些依据，并不表示每项模型尺寸和隐藏表面都已得到实测确认。

重复构件与结构尺度经过规则化处理，未逐件复刻局部变形、磨损和全部实物节点。隐藏榫卯与拼装方向包含几何假设。模型用于学习和可视化，不适合作为施工或文物修缮文件。

三种外观各有用途：

- **现状色** 根据建筑照片表达外观，以轻微明暗变化帮助区分构件。
- **彩绘色** 结合遗存痕迹与古制比较，探索彩画的配置方式。部分细节参考其他时期的做法，属于推定表达，尚不能确认为唐代原貌。
- **原木色** 使用暖木色板，帮助观察结构关系，不代表已确定原始木材树种或未涂饰表面的颜色。

本版本省略殿内佛坛、塑像及其扇面墙和折返墙。屋脊装饰及其他装饰细节为近似表达。颜色属于屏幕呈现，未经实物色度校准。渲染速度受设备、浏览器与模型细节影响；小屏幕上的细部观察体验可能较受限制。

## 主要参考资料

[`src/model/sources.ts`](../src/model/sources.ts) 中保存了更完整的逐构件参考资料及用途说明。可以从以下资料开始：

| 资料 | 主要用途 |
|---|---|
| 张荣、刘畅、臧春雨，[佛光寺东大殿实测数据解读](https://www.dpm.org.cn/building/talk/224453.html)，2007 | 基于测绘的结构尺度与构造分析 |
| 张荣，[东大殿建筑数字化勘察数据分析与唐代材分营造法式研究](https://www.kaah.or.kr/download/mailing/kaah_seminar_presentation1_1.pdf)，2022 | 数字化勘察分析与比例关系 |
| 梁思成，[记五台山佛光寺的建筑](https://www.thepaper.cn/newsDetail_forward_13478440)，1937 年调查，后转载 | 柱网、斗拱和梁架的历史记录 |
| 清源文化遗产，[佛光寺东大殿木构彩画及栱眼壁勘察](https://www.sohu.com/a/245954832_170361)，2018 | 现存彩画与填充部位的勘察记录 |
| Dapeng Cao，[A computer model for Chinese traditional timber structure: the Foguang Temple](https://digital.library.adelaide.edu.au/items/93341fe9-2e75-48bf-aa76-085add129a93)，2005 | 逐构件计算机建模及连接关系 |

其他建筑或历史时期的资料提供比较依据。历史测绘与近期照片也分别描述了建筑在不同时点的状态，理解模型时需要保留这些区别。
