# 木构图志 · Timber Atlas

[English](README.md) | 简体中文

[在线体验](https://timber-atlas.xiaodan.io/)

从一件构件开始，认识中国木构建筑。

木构图志 · Timber Atlas 是以山西佛光寺东大殿为对象的交互式三维建筑图解。你可以揭开屋面、查看梁架与斗拱如何相接，并练习拼装结构。探索时可切换中英文，构件说明将眼前的模型与资料依据联系起来。

## 开始探索

启动应用后，可以按这四步体验：

1. **看见木构架。** 在结构层列表中隐藏瓦作和望板，观察下方的木构。
2. **理解连接。** 选择构件，阅读名称、作用和连接关系；独立查看单件或所在组件，观察细部。
3. **拆开观察。** 拖动拆解滑块分离构件，或通过剖切观察内部。
4. **尝试拼装。** 进入「引导拼装」，选择一个局部研习，练习放置构件。

三种外观提供不同的观察方式：**现状色、彩绘色、原木色**。彩绘包含推定表达，详见 [模型资料与限制](docs/model-and-sources.zh-CN.md)。

拖动旋转视角，滚轮缩放，右键拖动平移。学习进度保存在你的浏览器中。

## 本地运行

需要 Node.js 24 和 npm。克隆本仓库并进入项目目录后运行：

```sh
npm ci
npm run dev
```

打开 Vite 在终端输出的本地地址。应用在你的设备上渲染三维几何，建议使用支持 WebGL 的桌面浏览器和鼠标。细节模型的加载可能需要一些时间，对性能较低的设备也有较高负担。

构建并运行静态网站还需要 Python 3：

```sh
npm run build
python3 -B scripts/serve.py --port 4173
```

打开 `http://127.0.0.1:4173`。构建产物位于 `dist/`。浏览器存储按主机名和端口隔离，更换其中任一项都会使用独立的学习进度存储。

如需在线托管，参阅 [Cloudflare Pages 与 R2 部署说明](deployment/cloudflare/README.md#中文)。本地开发继续读取本地模型，无需 Cloudflare 账号。

## 关于模型

东大殿将柱网、梁架、斗拱和屋面结构汇聚在同一座建筑中，适合用来学习木构件之间的组合关系。

本版本着重展示建筑结构，省略殿内佛坛、塑像及其扇面墙和折返墙，保留屋脊装饰。

模型依据已发表的测绘、建筑研究与照片制作，对尺度和重复构件进行规则化处理；隐藏连接及部分装饰细节含推定。它是一套附有逐构件资料说明的教学重建模型。如何理解这些表达，详见 [模型资料与限制](docs/model-and-sources.zh-CN.md)。
